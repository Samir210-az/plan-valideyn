# Valideyn Reabilitasiya Bələdçisi

AN Psixoloji Dəstək və Reabilitasiya Mərkəzi üçün hazırlanmış, **yalnız valideynin uşaqla evdə işləməsi** üçün nəzərdə tutulmuş fərdi gündəlik bələdçi. Tək HTML fayl olaraq internetsiz işləyir.

## Fərqi nədir?
`plan` repоsundan fərqli olaraq bu versiya mütəxəssis (Psixoloq/Loqoped/Erqoterapevt/Psixopedaqoq) bölmələri yaratmır — yalnız valideynin **Səhər / Gündüz / Axşam** üzrə konkret, addım-addım nə etməli olduğunu göstərir.

## Xüsusiyyətlər
- Eyni ətraflı qiymətləndirmə formu (şəxsi, klinik, inkişaf, nitq, sosial, davranış, sensor, motor, koqnitiv, ailə)
- Diaqnoza görə fərqlənən (autizm, Daun sindromu, serebral iflic, əqli gerilik, nitq pozuntuları, DEHB, ümumi) fəaliyyət bankı
- Hər gün 3 vaxt kəsimi: 🌅 Səhər, ☀️ Gündüz, 🌙 Axşam — hər biri üçün:
  - Konkret, ölçülə bilən məqsəd
  - Addım-addım icra qaydası (4 addım)
  - Material
  - Elmi əsaslandırma
  - Qiymətləndirmə/uğur meyarı
  - Uyğunlaşdırma tövsiyəsi
- 1 aylıq (30 gün) və ya 3 aylıq (90 gün) tam plan, hər gün fərqli
- Rəngli, tam müstəqil HTML ixracı, JSON ixrac/idxal, localStorage saxlama

## İstifadə
`index.html` faylını brauzerdə açmaq kifayətdir, internet tələb olunmur.
